# Contributing

PRs are welcome! Good first issues: new layouts (side-by-side, full-screen game + PiP face),
caption styles (karaoke highlight, colors), auto-detecting the face-cam, GPU encoding.

```bash
git clone https://github.com/MohdArhan2/video-clipper && cd video-clipper
pip install -e . pytest
pytest
```

Keep PRs small and focused, and add a test for any new helper function.
